# AI for Sustainable Development - Mental Health Emotion Detection 🧠💬

## 🎯 Objective
This project supports **UN SDG 3: Good Health and Well-being** by using Natural Language Processing (NLP) to detect emotions in text data, helping identify early signs of mental distress.

## 🧰 Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- NLTK / SpaCy
- Jupyter Notebook

## 📊 Dataset
The dataset used is **Emotions Dataset for NLP** (`train.txt`), containing text labeled with emotions like joy, anger, sadness, and fear.

## 🧠 Model
A machine learning classifier (e.g., Logistic Regression / Naive Bayes) was trained to predict emotions from text after preprocessing (tokenization, stopword removal, TF-IDF).

## 📈 Results
The model achieved good accuracy in predicting emotions.  
It demonstrates how AI can support **mental health awareness** through early emotion detection in social media or chat data.

## ⚖️ Ethical Considerations
- Ensuring data privacy and fairness.
- Avoiding bias in emotion recognition.
- Promoting ethical AI use in healthcare.

## 🧩 How to Run
1. Clone the repo.
2. Open `emotion_analysis.ipynb` in Jupyter.
3. Run all cells to see predictions and results.
